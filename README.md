# 오늘 점심 뭐 먹지?

HTML, CSS, JavaScript로 만든 간단한 점심 메뉴 추천기입니다. 등록된 메뉴 중 하나를 무작위로 골라 점심 메뉴를 추천합니다.

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다. 별도의 설치나 빌드 과정은 필요하지 않습니다.

## 주요 기능

- 처음 실행하면 김치찌개, 돈까스, 비빔밥, 파스타, 초밥이 표시됩니다.
- 새 메뉴를 목록에 추가할 수 있습니다.
- 등록된 메뉴를 개별 삭제할 수 있습니다.
- **추천 받기**를 누르면 현재 목록에서 메뉴 하나를 무작위로 추천합니다.
- 메뉴가 없을 때 목록에 등록하도록 안내합니다.
- 빈 이름이나 이미 등록된 이름은 추가하지 않습니다.
- 모바일 화면에서도 사용할 수 있도록 반응형으로 구성했습니다.

## 파일 구성

```text
.
├── index.html   # 페이지 구조
├── styles.css   # 화면 디자인과 반응형 스타일
├── script.js    # 메뉴 추가, 삭제, 추천 동작
└── README.md    # 프로젝트 안내
```
